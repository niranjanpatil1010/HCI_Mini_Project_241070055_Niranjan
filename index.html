    HCI principles applied

    This site was designed against Nielsen's usability heuristics and WCAG accessibility guidance. Each row shows where to see it.

    PrincipleHow it is applied
    Visibility of system statusReading-progress bar, highlighted current section in the menu, live project count, confirmation toast.
    Match with the real worldPlain language, resume-style section names, terminal motif suited to a CS audience.
    User control and freedomEsc closes dialogs, filters reset with "All", theme can be switched back, skip link for keyboard users.
    Consistency and standardsOne button style, one card style, standard nav at the top, links look like links.
    Error prevention and recoveryContact form validates on blur and submit, with specific messages that say how to fix each field.
    Recognition over recallAlways-visible menu, filter chips, Quick find lists every section and project.
    Flexibility and efficiencyCtrl+K quick find for experts, normal scrolling for first-time visitors.
    Aesthetic and minimalist designLimited palette, one accent colour, generous spacing, no decorative clutter.
    Orientation and wayfindingSide dot navigation shows where you are on the page; the journey map shows the education route; the progress bar and highlighted menu item track scrolling.
    Evaluation built inA System Usability Scale (SUS) tool lets test users rate the site; scores are averaged for the evaluation report.
    Motion and 3D with purpose3D and animation are decorative layers: nothing depends on them, every skill and project is also available as plain text, rotation can be paused, and all motion turns off when the system asks for reduced motion.
    AccessibilityContrast-checked colours, 44px touch targets, visible focus, ARIA labels, semantic HTML, reduced-motion support, light and dark themes.
    Fitts's and Hick's lawsLarge buttons for primary actions; seven menu items; project choices grouped into three filters.
